# Instrucciones de Mini Inventario

Mini Inventario es una aplicación web para gestionar productos y existencias.
El proyecto usa Node.js 22 y Python 3.12.
La aplicación web actual se ejecuta con Node.js.
Realiza cada cambio en una rama y prepara un pull request para revisarlo.
Lee el README y los archivos afectados antes de modificar código.
Nunca subas llaves, contraseñas, tokens ni archivos .env.
Mantén .env, venv y node_modules fuera del control de versiones.
Los archivos de ejemplo de configuración no deben contener secretos.
Solicita aprobación explícita antes de borrar datos.
Solicita aprobación explícita antes de desplegar o publicar la aplicación.
Explica el propósito de los comandos antes de ejecutarlos.
Verifica los cambios y registra los resultados reales en la entrega del día.
